# 🚖 RentSwift: Online Taxi Booking & Fleet Management System
*A full-stack ride-hailing platform built for the CDAC IACSD Capstone Project.*

---

## 📝 Project Overview
RentSwift is a comprehensive web application designed to streamline the taxi booking process. Built using a 3-tier architecture, it bridges the gap between taxi drivers and customers through a secure, feature-rich platform. Customers can book rides instantly, Drivers can manage trip statuses in real-time, and Admins have full control over the fleet, users, and analytics.

## 🛠️ Technology Stack
- **Frontend:** React (Vite) + TailwindCSS, React-Leaflet (Maps), SockJS & STOMP (WebSockets).
- **Backend:** Java Spring Boot, Spring Data JPA, Spring Security (JWT Authentication), Spring WebSocket.
- **Database:** MySQL (Relational, normalized to 3NF).
- **External APIs:** OSRM (Open Source Routing Machine) for map routing and distance calculations.
- **Deployment:** Vercel (Frontend) & Render / Railway (Backend).

## ✨ Key Features
- **Triple Role Dashboards:** Three distinct, secure interfaces for Admin, Driver, and Customer.
- **Real-Time Live Map Tracking:** Automatic WebSocket updates that plot the driver's car movement on the map along a calculated blue polyline.
- **Interactive Navigation:** Displays dynamic ETA countdown timers, distance remaining, and compass bearings during the trip.
- **Secure Admin Panel:** Full CRUD operations for Customers, Cabs, and Drivers.
- **Data Integrity:** Implemented **"Soft Delete"** for drivers to preserve historical booking records and prevent database foreign key errors.
- **Secure Payments & Feedback:** Integrated payment modal with receipt generation and a 5-star rating system upon trip completion.

## 🚀 How to Run Locally (Development Mode)

### 1. Backend (Spring Boot)
1. Open the `Backend Code Final` folder in STS (Spring Tool Suite) or IntelliJ IDEA.
2. Ensure your local MySQL server is running.
3. Update `application.properties` with your local MySQL username and password.
4. Run `RentalTaxiApplication.java`.
5. The backend API will run on `http://localhost:8080`.

### 2. Frontend (React + Vite)
1. Open the `Frontend Code Final` folder in VS Code.
2. Open the built-in terminal and run: `npm install`
3. Once installed, run: `npm run dev`
4. Open your browser and navigate to the Local URL provided (usually `http://localhost:5173`).

### 3. Database (MySQL)
1. Create a new MySQL database named `rentaltaxi_db`.
2. The schema is automatically generated by Spring Boot based on the JPA entities defined in the code.
